Homebrew-пейлоад (ELF), который читает датчики температуры PS5, управляет вентилятором по тихой настраиваемой кривой комфорта и содержит веб-интерфейс. Кроме того: управление играми, файлами, пейлоадами и профилем. Всё работает на самой консоли, без ПК и без интернета.

<details>
<summary><b>Все функции подробно</b></summary>

**Охлаждение**
- Удерживает целевую температуру (по умолчанию 66 °C, настраивается 60–91 °C) со скользящим средним, мёртвой зоной и трендом и меняет скорость только малыми шагами.
- Режимы тихий, сбалансированный и холодный, быстрый выбор и правила для отдельных игр.
- Выше температуры безопасности (по умолчанию 78 °C) решает только аппаратура; если приложение не запущено, консоль регулирует сама.
- Ночной режим: между двумя моментами времени действует более тихая цель; время берётся с устройства, на котором открыта страница.
- Самотест вентилятора одной кнопкой (отвечает ли вентилятор на порог?) и выученная минимальная скорость консоли (20 % в покое, 34 % в игре), которая видна в диагностике.

**Игры**
- Запуск (из браузера консоли страница закрывается сразу), закрытие, копирование на другие накопители, перенос или распаковка с ShadowMountPlus.
- Конвертация в образы exFAT, ffpkg и ffpfsc без ПК; всё перечитывается и проверяется после записи, с файлом `.sha256`.
- LZ4-ассет-паки, индекс AMPR, APR-EMU, заглушка PlayGo и модули DLC для каждой игры; проверка, распаковка и исправление образов.
- PS4 с USB: fake PKG PS4 с USB-накопителя в библиотеку без установки (PS4Mount от gasb07).
- Время игры с температурами, резервное копирование и восстановление сохранений, поиск, разделение и установка пакетов, история всех операций.

**Управление**
- Файловый менеджер: просмотр, скачивание и загрузка, создание папок, переименование, копирование, перенос, удаление (изменения только на накопителях и в `/data`).
- Пейлоады: просмотр и остановка запущенных, запуск своих `.elf` из папки или с USB, профили как последовательность запуска; загрузка и обновление пейлоадов из списка Payload Manager от itsPLK (с проверкой SHA-256).
- Профиль: отображаемое имя и изображение профиля (30 встроенных изображений или свой файл).
- Оформление: стандартное, светлое, тёмное и оптимальное (быстрее всего рисуется, рассчитано на телевизор); каждое устройство запоминает свой выбор.
- Система: модель, прошивка, время работы, хранилище, сеть; сырые датчики и диагностика в режиме эксперта.
- Шапка на каждой странице: режим покоя, перезагрузка, выключение, безопасный режим (по два щелчка).

**Техника**
- Собственный HTTP-сервер без сторонних библиотек, документированный [JSON-интерфейс](docs/API.md), настройки в `/data/PS5-Cooling-Center/config.json`.
- Без доступа к интернету, если не включить **обновления игр** (по умолчанию выключены): тогда приложение запрашивает у серверов загрузки Sony, а для старых патчей у prosperopatches.com или orbispatches.com обновления ваших собственных игр. Так же «Загрузка пейлоадов» получает список и файлы с GitHub только по нажатию кнопки. В остальном оно общается только с программами на консоли и с браузерами в домашней сети.

</details>

## Быстрый старт

1. Скачайте `PS5_Cooling_System_Center_v<версия>.elf` из [Releases](../../releases).
2. Отправьте его на консоль (загрузчик ELF, порт **9021**), например:
   ```bash
   nc -q0 <IP-PS5> 9021 < PS5_Cooling_System_Center_v1.71.4.elf
   ```
3. Откройте **`http://<IP-PS5>:8086`** в браузере (адрес также показывает уведомление вверху слева на ТВ).

> [!TIP]
> **Запуск без отправки:** распакуйте `PPSA86921.zip` из релиза и скопируйте папку в `/data/homebrew/`. ShadowMountPlus создаст плитку; одно нажатие запускает приложение и открывает интерфейс.

> [!IMPORTANT]
> Одновременно может работать только **один** экземпляр, иначе две программы будут спорить за вентилятор. Старый экземпляр можно остановить на странице «Пейлоады». Подробнее в [LIESMICH](docs/LIESMICH.txt) (на немецком).

## Требования

| | |
| --- | --- |
| **Консоль** | PS5 с джейлбрейком и загрузчиком ELF на порту 9021 ([elfldr](https://github.com/ps5-payload-dev/elfldr) или аналог) |
| **Проверено** | PS5 Pro (CFI-7021), прошивка 12.00; по сообщениям нескольких пользователей работает и на 13.60 |
| **Вентилятор** | [kstuff](https://github.com/EchoStretch/kstuff-lite) (без него работают датчики и интерфейс, но не регулировка) |
| **Сеть** | Браузер в той же сети или браузер самой консоли |
| **Необязательно** | [ShadowMountPlus](https://github.com/drakmor/ShadowMountPlus) для переноса, распаковки и плитки запуска |

<details>
<summary>Прошивка и SDK подробно</summary>

ELF собран с PS5 payload SDK **v0.44**, стартовый код которого знает прошивки **до 13.60**. Прошивка, которую стартовый код не знает, не доходит до `main()`: программа вообще не запускается и ничего не пишет в журнал. Для 13.00–13.40 сообщений пока нет (стартовый код их знает). Температура GPU есть только на Pro.
</details>

<summary><b>Сборка из исходного кода</b></summary>

Нужен [PS5 payload SDK](https://github.com/ps5-payload-dev/sdk) **v0.42 или новее** (проверено с v0.44); сборка это проверяет и останавливается со старым SDK. В Windows достаточно Git Bash с LLVM 21:

```bash
tools/build-windows.sh
```

В Linux или WSL:

```bash
export PS5_PAYLOAD_SDK=$HOME/ps5sdk/sdk
make
```

Результат — `PS5_Cooling_Center.elf`; `tools/make_starter.sh` собирает плитку запуска. Остальное в [docs/ENTWICKLUNG.md](docs/ENTWICKLUNG.md).
