# PS5 Cooling & System Center – Pro v1.71.0

## Neu
### Updates für SMP-Spiele
- Spiele, die über ShadowMountPlus laufen (exFAT- oder ffpkg-Abbilder), werden jetzt auf Updates geprüft und können direkt heruntergeladen und installiert werden
- Unter jedem SMP-Spiel mit Update steht ein Hinweis, dass das Update normal installiert wird; ob es auf das eingehängte Abbild angewendet wird, hängt vom Spiel ab
- Fake-PKGs bleiben weiterhin ausgeschlossen

### Doppelte Abbilder
- Die Karte „Doppelte Abbilder" startet eingeklappt und spart so Platz; ein Klick auf die Kopfzeile öffnet die Liste
