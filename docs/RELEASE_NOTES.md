# PS5 Cooling & System Center – Pro v1.76.7

## Highlights
- **Vollbild-App:** Die Titelzeile zeigt jetzt die **Version der App** gleich hinter dem Namen

## Neu

### Vollbild-App
- Oben steht „PS5 COOLING & SYSTEM CENTER Pro **v1.76.7** | Dateimanager“: Die Version folgt klein und gedämpft auf den Titel, der Name der Seite rückt ein Stück nach rechts.
- Die Zahl ist die Version der App, die auf der Konsole läuft (die Kachel liest sie beim Start von ihr), nicht die der Kachel selbst.

## Hinweise
- Die Kachel FAKE86921 (Vollbild) aus diesem Release neu kopieren, sonst fehlt die Version im Titel. FAKE86922 (Browser) trägt nur eine Kopie der ELF und ändert sich nicht sichtbar.
- Dieses Release enthält sonst nur die Änderungen von v1.76.6 (Rate und Restzeit beim Kopieren und Verschieben, Versionsnummer links im Browser).
