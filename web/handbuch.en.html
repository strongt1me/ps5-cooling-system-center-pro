Welcome

PS5 Cooling & System Center - Pro is a homebrew program (ELF) for a jailbroken PS5. It controls the fan according to a freely adjustable target temperature and comes with an interface – in the browser of any device on your home network or as a full-screen app on the TV. On top of that come games, packages, saved data, file manager, payloads, profile and system information.

Quiet, not loudThe control holds the target temperature gently and slowly, without constant ups and downs.
Browser or full screenOpen the address or tap the tile – nothing is installed on the PC.
Internet only on demandThe app goes onto the internet (GitHub) only when you trigger it: loading payloads, fetching newer versions of AMPR EMU NG, Dump Forge or Kraken Mount.
Safe to useActions work on the first click; only deleting asks first and names what will go. Running games and saved data are protected.
Tested on a PS5 Pro (CFI-7021) with firmware 12.00; users also report it working on 4.xx to 10.xx and 13.60.
2

Requirements

  • A PS5 with a jailbreak and a loaded ELF loader (elfldr, port 9021).
  • Firmware 1.00 to 14.22. On other versions the app does not start at all. 12.00 is tested.
  • kstuff must be loaded (for example via etaHEN) – only with it can the app reach the fan. Without kstuff the display and the interface work, but fan control reports “not available”.
  • A device with a browser on the same home network – or the console's browser or the full-screen app.
  • To send the ELF, nc (netcat) or another payload sender.
  • Optional: ShadowMountPlus. It creates the tiles and is needed for moving, unpacking and (from 1.7beta10) for mounting, unmounting and ejecting USB drives. Without ShadowMountPlus, Kraken Mount (tab “KrakenMount”, off by default) can take over the games in homebrew and etaHEN/games (chapter “Games”).
3

Installation & first start

  1. Send PS5_Cooling_System_Center_v1.99.0.elf to port 9021 of the console, e.g.:
    nc -q0 <PS5-IP> 9021 < PS5_Cooling_System_Center_v1.99.0.elf
  2. A notification with the address appears at the top left of the TV.
  3. Open it in the browser: http://<PS5-IP>:8086/

The tiles

With a tile you start the app without sending anything, even after a restart of the console. Copy the folder from FAKE86921.zip or FAKE86922.zip to /data/homebrew/ (by FTP or with the file manager); ShadowMountPlus adds the tile.

  • FAKE86921 – Fullscreen: starts the app if needed and shows it full screen with the controller (chapter “The full-screen app”).
  • FAKE86922 – Browser: starts the app as well and opens the web interface in the console's browser.
  • Update: copy the folders from the new release (close the full-screen app first). If an older app is still running when you tap the tile, the tile replaces it – except during a job (packing, copying, installing …): then it reports that a newer app is ready; open it again after the job.
  • Old page, new app: If a new ELF arrives while the web interface is open, “New version … running” appears at the top with Reload page. If the full-screen tile is older than the running app, “Tile …” appears at the top in yellow: copy the tile from the release again.
Only ever run one instance – two control the fan against each other. A newly sent ELF ends an older one itself; if that fails, end the old one on the “Payloads” page (Already loaded payloads → “Quit”) or restart the console.
If you send only the ELF and have neither of the two tiles, the app creates a tile under “Media” once by itself, about a minute after it starts (only if no game is running). It only opens the web interface and does not start the app; a deleted one does not come back.

The interface at a glance

On the left is the sidebar with Cooling, Games, File manager, Payloads, System, Profile, Log and Credits, below them Manual, FAQ and the version of the running app. At the top is the header with Power options, language, design, “Fullscreen” and the connection indicator. Expert mode (raw and diagnostic values, advanced settings) is switched on on the System page and is off by default.

  • Power options: Rest Mode, Restart, Turn off and Safe Mode. Every command works on the first click.
  • Language: Deutsch, English, Italiano, Español, Français, Русский or Svenska. “Auto (system)” uses the console's language in the PS5's browser, otherwise the browser's (if that is not available: English). Notifications that the console shows on the TV are in German.
  • Design: Standard (dark blue, glowing edges), Light, Dark (almost black) or Optimal (for the TV and the PS5's browser: strong contrast, larger text, the fastest to draw). Every device remembers its own choice.
  • Fullscreen hides the browser's taskbar and window frame; in the PS5's browser the first press on the page already switches over.
  • Manual and FAQ open these texts in the chosen language (without screenshots).
When turning off or restarting, unsaved game progress is lost.

Controller in the PS5's browser

L1/R1 go to the previous/next page, L2/R2 scroll the page up/down. When a window is open (e.g. for deleting), the background stays still, and the right stick scrolls only the window.

Cooling

The most important page: status in plain words, temperatures, the fan and the running game. Below it you set the Target temperature and the Operating mode.

Target temperature and operating mode

  • Target temperature: the temperature the console should hold – 50 to 91 °C, 66 °C by default. Higher means quieter and warmer. Quick select sets Cool 62 °C, Balanced 77 °C or Quiet 91 °C.
  • Operating mode Quiet (recommended), Balanced or Cool: how strongly the fan responds to heat. It does not change the target.
  • Automatic mode off: the app hands the fan back to the console and only shows values. If the app is not running, the console controls the fan itself anyway.
91 °C is the value the console sets itself: the fan stays as quiet as without the app, but the console gets noticeably warmer. The emergency limit is always at least 4 °C above the target (so 95 °C at 91 °C).

How the control works

  • It works with a moving average and watches the trend: if the temperature is already falling, the fan is not turned up any further.
  • The speed already rises gently 10 °C below the target (from about 23 %), is 28 % (Quiet), 33 % (Balanced) or 40 % (Cool) at the target and reaches full speed about 24, 17 or 14 °C above the target.
  • It turns up in small steps and turns down only once the temperature has been stably low.
  • Above the emergency limit all consideration for loudness is dropped; the fan goes quickly to full speed. The firmware always protects itself in addition.
  • The console never goes below its own minimum speed (measured: 20 % at idle, 34 % in a game); the app shows it in the fan diagnostics.

Fan guard

A second, independent part of the app checks the temperatures every second:

  • If the control stays silent for 20 seconds, it hands the fan back to the console; if it is hot, it sets full cooling.
  • If the temperature stays above the emergency limit + 6 °C (84 °C at the earliest) – for 10 seconds while the fan is not at full speed, or for a minute despite a full fan –, it holds full cooling until it is 8 °C cooler.
  • If the app crashes, the console gets the fan back.

While it steps in, the page shows “Watchdog”, and a fixed threshold set by hand is refused.

Night mode and profiles per game

  • Night mode: between two times (e.g. 23:00 to 07:00) the night target applies instead of the target, usually warmer and quieter. The time is that of the device on which the page is open.
  • Profiles per game switch the target and operating mode as soon as a certain game runs: start the game, set the target and operating mode, Remember current setting; Remove takes the profile away. Up to 16 games; Game detection is needed (System → Extra queries, on by default). A game profile takes precedence over night mode. Full-screen app: Cooling → Settings → Game profiles.

Ceiling, warning and emergency limit

  • Fan speed ceiling (30 to 100 %, 100 % = no limit by default): in normal operation the fan does not go faster. Each operating mode already has its own limit (Quiet 65 %, Balanced 85 %, Cool 100 %); the ceiling can only lower it. It does not apply above the emergency limit or in the fan guard. A low ceiling means a warmer console.
  • Warning from (Expert view → Advanced settings; 40 to 110 °C, 80 °C by default): from this processor temperature a notification appears on the TV; for the main chip 5 °C more applies. With Warning threshold follows the target (on by default) it is never below target + 2 °C in automatic mode.
  • Emergency limit (same place; 72 to 95 °C, 78 °C by default; in the full-screen app “Safety limit” under Cooling → Settings): from here full speed regardless of loudness. A last resort – best left as it is.

Fan curve, control recording and fan test

  • Fan curve (full-screen app: Fan curve tab): shows what speed automatic mode asks for at which temperature, with a dot for right now.
  • Control recording: the last 30 minutes of the control, one line per second, in memory only. Download control recording downloads it as CSV, Save on the console puts it in the data folder (full-screen app: X button).
  • Test the fan now (expert view, “Fan diagnostics” card): briefly lowers the threshold and checks whether the speed rises by at least 8 percentage points. The fan gets audibly louder for up to 30 seconds; the test only runs when the console is cool.

Display via the mute button

Press the controller's mute button twice quickly: the processor temperature and fan speed appear at the top left without a sound – even without the interface. The microphone is then as it was before. At most every 5 seconds; can be turned off with Display via the mute button (“Operating mode” card).

Pause the game in the background

When a game goes to the background and the Home screen is in front, the app pauses the game. That way a tile of the app starts afterwards without an error message (“Device busy”). Only games are paused (no media apps such as YouTube, no tiles of the app), once per stay in the background; the game then carries on where it was. Switch Pause the game in the background below the operating mode (on by default; full-screen app: Settings).

7

Games

The library shows the games on your Home screen with cover, format and actions.

  • Search by title, title ID or content ID, filter by PS5, PS4 or “Backport · AMPR · PlayGo”, sort as on the Home screen, by name, last played, play time, size or installed.
  • View: “large (as before)” or “compact” (small picture, the buttons as icons; if you point at an icon with the mouse or the D-pad, or press “i”, the bottom says what it does). The browser remembers the choice per device.
  • Info & metadata expands the details of the game. Open path jumps in the file manager to the game's folder (for an image: to the image file).
  • In the full-screen app the Square button opens a game's actions, the Triangle button the details.

Starting and closing

  • Start starts the game directly. The console's browser closes in the process so that the game is in front. Replies from the console (a refusal, an offer “Start”) come as a notification at the top right.
  • If another game is already running, Start closes it and starts the chosen one in one go. Close game closes the running game at once, without a question. In both cases anything not saved is lost.
  • A running game cannot be started a second time: a second start of the same title can crash the console. A second click on Start does nothing while the first start is under way and for 30 seconds after it.
  • If ShadowMountPlus refuses a start with “Device busy”, the app tries twice more by itself, 3 seconds apart.

Mounting and unmounting

Mount, Remount and Unmount (through ShadowMountPlus from 1.7beta10) help when a game hangs or should be detected anew after copying, moving or deleting. Not while the game is running.

A mounted game that is not running blocks every other start, tiles included (ShadowMountPlus reports “Device busy”). The Games page then shows a yellow notice with Unmount (full-screen app: mark MOUNTED). A game the app mounted itself is released by the app on its own: at once when it starts another game or the console refuses a start (then simply start again), otherwise after 30 seconds. The 30 seconds only run while no game and no job of the app is running. Whatever the app did not mount, it leaves alone.

One game at two mounters

Kraken Mount, ShadowMountPlus and PS4Mount register every game they find with the console. If the same title ID lies with two of them (for example a .pkg for Kraken Mount and an image for ShadowMountPlus), they get in each other's way: “Device busy”, one takes the other's mount away, the tile differs. The KrakenMount tab then shows a yellow caution notice. The app moves nothing itself: keep every game with only one mounter, and put games for Kraken Mount only in the folder Kraken-Games, where ShadowMountPlus does not search. If a game that lies with both anyway is ended, the app unmounts it at ShadowMountPlus.

Duplicate images

If a game exists in several images (.exfat, .ffpkg, .ffpfs, .ffpfsc), ShadowMountPlus takes one now, the other next time. Then the collapsed card Duplicate images appears; a click on its header expands it, and the source in use right now is marked. Deactivate renames an image to ….off, Activate undoes it; nothing is deleted. A mounted image, or one whose game is running, cannot be deactivated.

The bar above the library shows the app's running jobs and also moves, unpacks and installations that ShadowMountPlus carries out itself.

Stutter with ffpfsc: the console has to unpack a compressed game over and over while playing. Games with a great deal of data or texture streaming can therefore stutter. The window shows a note next to the “ffpfsc” entry from about 40 GB of data, with large streaming containers (.ucas, .utoc, .pak, .forge, .streamdb, .resources, .cas, .rpf; 4 GB together or more) or with a streaming folder of 2 GB or more. This is an estimate from names and sizes; “Start” converts without any further question.

Moving and unpacking are carried out by ShadowMountPlus itself; the app plans the job and shows it. Games are moved only into folders in which ShadowMountPlus searches (homebrew, etaHEN/games, on USB and M.2 the root), and the old place is deleted only when everything has arrived. You unpack an image in the “Convert” window with Dump folder · extract into a folder with the title ID (for an .ffpfsc, “Convert” opens this window directly). For another format, unpack first, then convert the folder. If unpacking ends at ShadowMountPlus with “Permission denied”, the app carries on unpacking itself.

Check afterwards: Thorough (the default) reads the result back in full, checks every block and creates <name>.sha256. Quick checks the structure and a sample, without a checksum file: that saves a lot of time with big games, but does not find a damaged block outside the sample.

Before the start: check, name, queue

  • The window checks everything beforehand and shows it as a list: source readable, space on the target, FAT32 (no file over 4 GB), name already exists, running game, damaged Home screen picture (icon0, pic0, pic1, pic2.png). Red blocks the start, yellow only warns.
  • Name of the result: it follows the game's folder. A template made of {titel}, {id}, {version} and {quelle} changes it, for example {titel} [{id}] v{version}; the window shows the finished name.
  • While it runs, a line shows the steps (measuring, writing, compressing, checking, renaming) with their duration.
  • Add to queue lines up several games one after the other. An error does not stop the queue, and a failed entry can be retried. After a restart of the app it is empty.
  • If the source changes while the app is working, the app does not adopt the result and names the file.

Original afterwards

When converting, copying and unpacking, you choose under “Original afterwards” what happens to the original (in the full-screen app too):

  • Keep (the default). The title then exists twice, and ShadowMountPlus reports it from two places.
  • Delete: asks first and names the name, size and path; saved data stays. If Kraken Mount plays the original, Kraken Mount deletes it. If the result was checked only with Quick, the original stays in place (then choose “Thorough”).
  • Move: first a checked copy into a folder of your choice on the internal SSD, M.2 or USB (suggested: PS5-Sicherung/Spiele), then the original is deleted. The app refuses folders that ShadowMountPlus or Kraken Mount search, as well as a name that is already taken or too little space. On the same drive (except the internal SSD) it is only renamed. If Kraken Mount plays the original, Move is not possible.

The original is deleted or moved only after the job has ended well; if it fails or you cancel, the original stays untouched. While the original is being worked on, no other job starts. If the app restarts in that time, it reports at the next start what was left open and where the rest lies.

PS4 game folders and unsigned executables

PS4 dump folders (only sce_sys/param.sfo) can be converted into ffpfsc, ffpkg or exFAT as well; ShadowMountPlus mounts them from 1.7beta8. The target can only be a USB or M.2 drive.

A PS4 title from the console's storage crashes it. Trophies do not work for PS4 games from images (0x80551618), and some titles get stuck at “Please wait”: both only work with a real installation (“Packages” tab).

Unsigned executables: if a game's eboot.bin, .prx, .sprx, .elf or .self are plain ELF files, the console does not start it. The window names them beforehand, and the image gets them fake-signed as FSELF; the game folder stays unchanged. Files that are already signed stay as they are.

Debug FPKG with Dump Forge

The format FPKG builds a debug package (.pkg) that Kraken Mount mounts. It is written by Dump Forge (quer3q, GPL-3.0), which is built into the app (version 0.6.0, also in the plain ELF; nothing to fetch). The app starts it for every job, shows its steps and ends it afterwards. “Add to queue” and “Original afterwards” work as usual.

  • Levels: Fast (recommended), Balanced and Smallest (about 2.6 % smaller, but they take about 6 and 9 times as long) and Uncompressed (for the case that the console does not start a compressed package).
  • Target: “B · Playable with Kraken Mount” (preselected) or “C · Backup”. The name may have at most 63 bytes (without “.pkg”).
  • Check: Thorough reads every byte of the package, Quick checks the structure and a sample; no checksum file is created.
  • Games with AMPR packs are unpacked by Dump Forge in the process, because Kraken Mount does not accept a package with packs. The package gets correspondingly bigger, and it takes longer; the window says so beforehand. If a game has zstd and LZ4 packs at once, FPKG is locked: unpack one kind first.
  • If the original with the same title ID is mounted by ShadowMountPlus, unmount it first.
  • Newer version: Download newer version from GitHub in the window (only on a button press, HTTPS, checksum from SHA256SUMS), or put the file ps5-dump-forge-<version>-ps5.elf (newer than 0.6.0) into /data/PS5-Cooling-Center/dumpforge/ by FTP or the file manager. The highest version wins; the app does not need a restart.

Packing while converting

For exFAT and ffpkg from a PS5 game folder, the window offers the group Packing (AMPR packs): Do not pack (the default), LZ4 packs (level 9 recommended, 3 fast, 12 smallest) or zstd packs (AMPR EMU NG only) (level 5 recommended, 1, 9, 19). Dump Forge then writes the image and packs on the fly, without a temporary folder; AMPR EMU NG goes into the game, and the original stays unchanged.

  • Dump Forge reads the source twice (first measuring, then writing), which is why it takes longer. At the end it says how much smaller the image is.
  • Everything except the system files is packed; there is no profile here, “Build the AMPR index first” does not apply, and no .sha256 is created. The name may have at most 63 bytes.
  • Locked for PS4 games and for games that already lie in packs (unpack first). For ffpfsc there is no such choice.
  • Try it on a small game first: whether a packed game runs depends on AMPR EMU NG.
Please recreate .ffpkg images from app versions before 1.48.0 (old structure).

PS4 games from USB (PS4Mount)

The tab PS4 PKG from USB plays PS4 games (fake PKG) straight from the USB drive, without installing them. It is based on PS4Mount by gasb07 (GPL-3.0), whose source code is built into the app, and is switched off by default.

  1. Prepare: put the game, update and add-ons as .pkg on an exFAT drive, in any folders and with any names (the search can be limited to certain folders in the settings). What has the same title ID belongs together. The PKGs stay where they are.
  2. Switch on: the switch starts the search and stays on across a restart of the app (switched off, it stays off). “Search now” searches at once.
  3. Wait: every game appears with its icon on the Home screen as soon as it is ready. With several updates the newest applies (“Updates” chooses another).
  • Only small management files go onto the console. Deleting on the console or Remove tile only takes away the tile; Restore tile brings it back.
  • Updates (patch.pkg) always come along, add-ons only when the switch in the settings is on.
  • Found, not set up lists PKGs the search leaves alone, with the reason: already installed (delete the installed game first), not fully copied yet, not a PS4 package or not a fake PKG, add-on without a game, second copy, damaged package (never registered, as it can turn the console off and damage its storage), on the M.2 expansion (the console does not start PS4 games from there: put them on a USB stick with exFAT). The list is also shown in the full-screen app.
  • No merged PKGs: game PKGs with built-in updates or add-ons may not run. Better: the original game PKG, with the update and add-ons as separate files beside it.
  • The app must be running for the games to stay visible after a console restart. If a stand-alone PS4Mount (ps4mount.elf) is already running, the tab shows “waiting” and takes over as soon as it has ended.
  • From firmware 6.00 the console registers the games the usual way. Below that, one at a time; if the needed function is missing there, no games are added, to protect the database.
  • If a drive comes back as usb1 instead of usb0 after a restart, its games stay registered.
  • Limits: up to 768 games and 64 search folders per drive; a running game uses at most about 30 packages (a limit of the console).

Move PKGs back: older versions of PS4Mount moved PKGs to ps4/CUSAxxxxx. “Move PKGs back” (per game), “Move selected back” or “Move all back” puts them back in their old place with their original names; the game stays in the library. A running game is closed first. No file is replaced or deleted.

Close PS4Mount games before Rest Mode: Rest Mode switches the drive off, and an open game then hangs. It is safe to switch PS4Mount off beforehand: that unmounts all games (if one is running, the app refuses and names it). Two or more drives or partitions can make the console sluggish; then connect only one.

Games with Kraken Mount (KrakenMount)

The KrakenMount tab plays debug FPKG (.pkg), game folders (unpacked, zstd, LZ4) and images (.exfat, .ffpkg, .ffpfs, .ffpfsc) without installing them. For this the app brings the program Kraken Mount by quer3q (GPL-3.0, version 0.4.2), starts it and shows its games. Every game gets a tile of its own. Kraken Mount brings AMPR EMU NG, the PlayGo stub and dlc_emu itself and puts them into the fakelib of a game that needs them; they do not count as a backport.

  • Where the games go: into the folder Kraken-Games, directly or into a subfolder. Internally that is /data/Kraken-Games (the app creates it), on USB or M.2 the folder Kraken-Games in the main folder (you create it, or copying and converting with target “B” do). ShadowMountPlus does not search there. Backports go to <search folder>/backports/<TITLE-ID>*. An old folder FPKG-Games is renamed to Kraken-Games when switching on, as long as the search folders are still the ones the app created.
  • Switching on: the “Switch on” switch starts Kraken Mount (off by default). Once it is switched on, the app starts it by itself every time the app starts. Stopping is refused while a game is running. Kraken Mount must be running for its games to stay visible after a console restart. If the old version is still running after an update of the app, the page says so: switch it off and on again.
  • List: name, title ID, version, size, drive, kind (FPKG, folder or image) and state. Per game: Rebuild (rebuilds the cache under /data/krakenmount/caches), Delete game (asks; deletes the file, folder or image together with the tile and cache, saved data stays) and Turn PlayGo stub off or on (only for games that load PlayGo: off when the game stays on a black screen; on when it asks you to finish the download). Plus Search now, Rebuild all and the log.
  • If a game's source is missing for 5 minutes (for example an unplugged drive), Kraken Mount removes it from the Home screen; it comes back with the source.
  • Download newer version from GitHub fetches the newest release (only on a button press, HTTPS, checksum from SHA256SUMS); the next start uses it. Settings such as search folders and fakelib, ejecting USB drives and installing an FPKG to the console are offered by Kraken Mount's own page (port 8097, button “Kraken Mount page”).
  • Full-screen app: Games → KrakenMount. Square button: Rebuild, Delete, PlayGo stub; Triangle button: on/off, search, Rebuild all, newer version, log.

Without ShadowMountPlus: if ShadowMountPlus is not running (for example not loaded after a restart), the app gives Kraken Mount the folders of ShadowMountPlus as well after a minute: homebrew and etaHEN/games (internal and on every drive) and the main folder of every drive. Kraken Mount then registers the games there itself, the tiles of homebrew programs too; it plays a .pkg in the main folder of a drive without installing it. When ShadowMountPlus starts, the app gives the folders back within a few seconds. Every start of Kraken Mount by the app begins without these folders, so that a ShadowMountPlus from the autostart has time; a folder list changed by hand on its page stays untouched. A lamp in the tab shows the state:

“Delete” in the game list goes through Kraken Mount itself for a Kraken Mount game (see the chapter “Deleting games & backups”).

Image on USB: if Kraken Mount has mounted an image from a USB drive, the app does not eject that drive. Unmount the drive on Kraken Mount's page first.
Only start it through the tab: a Kraken Mount ELF that you send to the ELF loader yourself waits until ShadowMountPlus has ended (“waiting for ShadowMountPlus”), looks for updates by itself and answers on ShadowMountPlus's port (the app then sends ShadowMountPlus no jobs). The built-in version does none of this.
No shared folders: if you point Kraken Mount at folders that ShadowMountPlus also searches, every game there is registered twice.

Notes: for large, demanding games the author recommends zstd-packed games instead of a .pkg. If the param.json has “upgradable” as applicationDrmType (many images do), the tile shows a padlock, because Kraken Mount registers the file unchanged; the game starts anyway.

AMPR index, APR-EMU, PlayGo and history

Every game card has the button LZ4/zstd asset packs …; for an image it is called AMPR & APR-EMU …, because LZ4 and zstd only work with dump folders. The window brings together the AMPR index, APR-EMU in the game, PlayGo in the game, packing (chapter “LZ4 asset packs: step by step”), the Optimization by recording, the Game plugins and, for an image, checking, unpacking and repairing.

AMPR index

  • The AMPR index (ampr_emu.index) is the list of all of the game's files with which APR-EMU finds them. The window shows whether there is one and how many files it knows.
  • Build / Rebuild creates it; for an image, ShadowMountPlus briefly mounts it for writing. The old index stays as ampr_emu.index.bak. The layout follows build_ampr_index.py by drakmor (GPL-3.0).
  • When converting a dump folder, the box Build the AMPR index first puts the index into the image right away (preselected for games with APR-EMU). For .ffpfsc this is the only way, as nothing can be written there afterwards.
  • A running game or another job of the app blocks building.

APR-EMU in the game

The row shows which libSceAmpr.sprx the game loads. You can choose a version and put it in, bring the game's file back with Restore original (it is backed up once as libSceAmpr.sprx.orig and never overwritten) or delete only the APR-EMU file with Remove.

Group in the listBundled versions
AMPR EMU NG @quer3qNG 0.5.1, NG 0.5.1 debug, NG 0.5.0, NG 0.5.0 debug; reads LZ4 and zstd packs

LZ4 asset pack version0.4.2.1 test-pack and test-debug-pack, for LZ4 packs only

  • Check for a new AMPR EMU NG version and load it fetches the newest stable NG release from GitHub (only on a button press, never a beta, checksum from SHA256SUMS). In exchange, the oldest NG version offered drops out; your own files stay.
NG and the fakelib update of ShadowMountPlus: if it is on, ShadowMountPlus replaces the NG file at game start with the one from its emulator folder again. So when you put NG in, the app asks: Yes turns it off (only this one setting in /data/shadowmount/config.ini, backup as config.ini.ps5cc-bak) and puts NG in, Cancel leaves everything as it is. By hand it works with the switch Update fakelib automatically in the ShadowMountPlus card on the System page (full-screen app: System → ShadowMountPlus). There you can also set whether ShadowMountPlus from or before 1.7beta12 is running (default: detect automatically); the app understands both formats of config.ini.

Where the file goes: ShadowMountPlus looks first in the backport folder <scan path>/backports/<title ID>/ (also a folder whose name begins with the title ID), then in the game; the first folder that exists counts alone.

  • Game folder, .exfat, .ffpkg: to fakelib/libSceAmpr.sprx in the game. For an image you can also choose the backport folder under “Where does the file go?”; if the image is full, the app takes it by itself.
  • .ffpfsc: cannot be written to. The file goes into a backport folder, and because that hides the game's fakelib, its files are copied along.
  • If a backport folder already exists, it applies to every format.
  • The window warns when a fakelib2 lies beside fakelib (ShadowMountPlus then reads only that one) or when ShadowMountPlus replaces the file at game start. A game in LZ4 packs accepts only “pack” versions, a game in zstd packs only NG.

PlayGo in the game

The same for libScePlayGo.sprx, drakmor's PlayGo stub (pgo_stub, GPL-3.0). It reports everything as completely installed to a game whose PlayGo content cannot be found; so it only helps games that treat PlayGo content as missing. Bundled are 0.6 “nolog” and “log” (writes /app0/playlgo.log into the game), stored in /data/PS5-Cooling-Center/PlayGo. Place, backup as .orig, backport folder for .ffpfsc, warnings and removing work as with APR-EMU; the two files can be changed independently of each other. A stub in /data/shadowmount/emus wins.

Check, unpack, repair an image

For an image (.exfat, .ffpkg, .ffpfsc), the app reads it itself, without mounting it. A running game or another job of the app blocks these tools.

  • Check image: reads every file in full (for .ffpfsc first every block with its checksum) and names affected files, with the place where the trouble starts. A drive that is going bad shows up this way too.
  • Unpack into a folder: writes all files to homebrew/<name of the image> on a drive of your choice (FAT32 takes no files over 4 GB), reads each one back and compares it. Only then does the folder get its name; on an error or cancel it is removed. The image stays; the game then exists twice.
  • Repair: only where it is safe: a wrong file size of an .ffpfsc whose data is complete. Damaged blocks cannot be restored. Locked while ShadowMountPlus has the image mounted.

Game plugins

The row keeps drakmor's replacement modules in the game's fakelib up to date: the PlayGo stub (pgo_stub 0.6) and the DLC modules of dlc_emu 0.3 (libSceAppContent.sprx, libSceGameUpdate.sprx, libSceNpEntitlementAccess.sprx, “log” build, writes /app0/dlc_emu.log), which show the DLC from the game's dlc_emu.ini as owned.

  • A known older build is replaced (the old one stays as .old); an unknown one is left alone.
  • The PlayGo stub is never newly added to a game (that is done under “PlayGo in the game”). The DLC modules are only added when there is a dlc_emu.ini in the game folder; otherwise they would hide the real DLC.
  • If a library lacks the execute permission, “Refresh” sets it; without it the console does not load the library (“mount flag / attribute error”).
  • If the game has a fakelib2 or ShadowMountPlus reads a backport folder, the app changes nothing.

History

The History tab on the Games page shows all of the app's jobs, such as copying, converting, installing, deleting, file manager, saved data, disc images, dumps, AMPR index, APR-EMU, PlayGo, LZ4 packs and the image tools, with the result (Done, Errors, Cancelled), size, duration and time. The last 500 are kept in /data/PS5-Cooling-Center/history.jsonl; Clear history deletes them after a question.

9

LZ4 asset packs: step by step

An asset pack consists of a few files (ampr_assets-000.pak and more, plus ampr_assets.index). The app packs the game data into them and shrinks it with LZ4; while you play, APR-EMU unpacks each block only when the game needs it. According to the developer (drakmor, ampr_emu) this halves the space needed and often loads 30 to 40 percent faster. Version 0.4.2.1 is expressly a test version: not every game tolerates it.

What you need

  • The game is a folder. Turn an image into a folder first with Unpack into a folder.
  • The game links libSceAmpr: the app shows ✓ loads libSceAmpr itself. With ✗ does not load libSceAmpr itself the button is locked, because the game would not find its files in the packs. Such games can only be compressed to .ffpfsc.
  • ShadowMountPlus in a current version, with images mounted read-only (the default).
  • Space: when packing in the game folder, the app needs about half of the game data extra until the originals are removed.

The “Pack with LZ4 …” window

  • How strongly? Level 3 (fast), 9 (balanced, recommended) or 12 (smallest).
  • What goes in? A matching tested profile (then already selected), Automatic or an own profile (TOML in the format of drakmor's ampr_pack.py) from /data/PS5-Cooling-Center/LZ4_Profile or the folder LZ4_Profile of a USB drive; Add profile … puts a file there. Programs, system folders and the packs themselves always stay loose. The window shows beforehand how many files will be packed.
  • What happens to the originals? Pack in the game folder saves the most space: every file is compared byte for byte with the packs, and only then is the original removed; on an error everything stays as before. Or as a new folder <name>-lz4 beside it: the original stays untouched, but two folders with the same title ID can make ShadowMountPlus remount the game every second. Then take the original out of the search path first.

Step by step

  1. Install APR-EMU: under APR-EMU in the game choose the version 0.4.2.1 test-pack. Only versions with “pack” in the name read packs.
  2. Test unpacked: start the game and play for a while (menu, a level, load a save). If it does not run like this, it will never run packed. Then only an older APR-EMU helps (for example 0.3.6.6, with Add file from drakmor's releases page), or none.
  3. Pack: Pack with LZ4 …, to begin with level 9 and Automatic (or the tested profile); the box “started unpacked, and it ran” belongs to it.
  4. Check packs: reads every block, unpacks it and compares it with its checksum. In the process it fixes what good packs also need: it puts the APR-EMU that reads packs back in, brings back files that the PS5 looks for outside the packs, and sets the permissions in the game folder to 0777. What it fixed is listed under Repaired. This shows that the packs are intact, not that the game uses them correctly.
  5. Start and play: only now does it show whether it runs. Play for longer than a few seconds, with loading and saving.
  6. If it does not run: Unpack LZ4 … writes all files back, compares them and removes the packs.

A packed game carries the mark LZ4 packed. While it is packed, the AMPR index is locked, and the APR-EMU can only be swapped for another “pack” version. The app keeps packing at low priority even when the window is closed; a running game must be closed first.

Tested profiles

The app ships four profiles that danthespal wrote and tested on the console: ASTRO BOT, EA Sports UFC 6, the Insomniac engine (tested with Marvel's Wolverine) and the Unity engine (tested with God of War Sons of Sparta). If one fits the game (title ID, name or file layout), the row shows ✓ tested profile, and it is selected when you pack. A profile of your own whose name starts with the title ID (for example from the recording) comes first. Under Own profile the four are available for other games too; whatever a profile does not name stays loose.

What stays loose

  • Always: empty files, the PlayGo markers (cache_ps5/pgc_*_dummy_file, cache_ps5/playgo.pgm), the boot files Ghost of Yōtei needs to get past the black screen, and *.rmdtoc (Alan Wake 2). The PS5 looks for them outside the game, where APR-EMU cannot help.
  • With “Automatic” also: programs and libraries, sce_sys, sce_module, fakelib, saved data, already compressed media (mp4, webm, ogg, wem …), configuration and data files (.json, .xml, .ini, .dat, .bin, .utoc), archives, the game's own .pak files, the folders trophy2, uds, _DUPLEX_, decrypted and movie folders, Wwise sound banks, files directly in the game folder and very large files that hardly pack.
  • Everything the app writes into a game folder gets the permissions 0777, also when copying, when unpacking an image and in the file manager.

If the game does not start or crashes

  • First find out who is to blame: unpack the game and start it unpacked with the same APR-EMU version. If it crashes like that too, packs are not possible for this game.
  • “mount flag / attribute error” in the ShadowMountPlus log: the library lacks the execute permission. The app creates it with 0755; if you copied the file yourself, run SITE CHMOD 755 over FTP.
  • SIGBUS or CE-108255-1 right at the start: eboot.bin or modules lack the execute permission, typically after a copy from an .exfat image. Check packs sets the permissions.
  • Notice under the packed game: either eboot.bin must not be executed (“Check packs” helps), or ShadowMountPlus does not include a fakelib for the game. Then APR-EMU is missing at the start; in the web interface of ShadowMountPlus set the game's mode to “Emulators” or “Full”.
  • Crash after a few seconds although it ran unpacked: the game probably reads files through mmap or for writing; such files must stay loose. In your own profile add a loose rule for the file at the end (the last matching rule wins). Which files the game could not open is written by 0.4.2.1 test-debug-pack as apr.pack.open.fail in ampr_emu.log.

Better than “Automatic”: the recording

“Automatic” only knows what is on the disk. A profile made from a real play session is more reliable. The row Optimization by recording does that in four steps:

  1. Start recording: the app puts the debug APR-EMU (0.4.2.1 test-debug-pack) into a folder fakelib2 of the game (ShadowMountPlus then reads only that one). Requirements: the game loads libSceAmpr, the AMPR index is built, the game is not packed.
  2. Play: play for a while and quit the game normally. The debug version is slower.
  3. Collect session: after every session, because the recording is emptied at every start. Stored in /data/PS5-Cooling-Center/traces/<title ID>/. Several sessions (other levels, other game modes) make a better profile.
  4. Create profile: this creates <title ID>-mitschnitt.toml in the folder LZ4_Profile, with a suitable block size and layout per file. Files that were never read stay loose. When packing, choose it under Own profile.

Then Stop recording: that removes fakelib2 again. A recording only knows the scenes you played; for anything else, add rules of your own.

zstd instead of LZ4 (for AMPR EMU NG)

Pack with zstd … creates ampr_zstd.index and ampr_zstd-000.pak (and more). The format comes from quer3q (ampr-emu-ng) and is read only by AMPR EMU NG; the app puts NG into fakelib itself while packing. Turn off the fakelib update of ShadowMountPlus (chapter “AMPR index, APR-EMU, PlayGo and history”), otherwise the result shows a warning.

  • The whole game is packed except the system files (programs, sce_sys, sce_module, fakelib, .ini files such as dlc_emu.ini, empty files); there is neither a profile nor “Automatic”.
  • Level 5 (default), 1, 9 or 19: higher levels save more space but pack much more slowly. While playing, hardly anything changes.
  • Packing always happens in the game folder; the originals go only after the byte-for-byte comparison. Beforehand you confirm that the game ran unpacked with NG. Check packs and Unpack zstd … exist as with LZ4.
  • A game lies either in LZ4 or in zstd packs, never in both; to switch, unpack first.
  • Try it on a small game first. Whether a packed game runs depends on AMPR EMU NG; “Unpack zstd …” brings all files back.

Packing right while converting into an .exfat or .ffpkg: see the chapter “Games”, section “Packing while converting”.

Does the index fit into AMPR EMU NG?

AMPR EMU NG builds tables from the index that must fit into its index memory (80 MiB with the bundled versions 0.5.0 and 0.5.1). If they do not fit, NG serves no packed file, and the game does not start. So for a packed game the window shows the row Does the index fit into AMPR EMU NG? with “fits”, “tight” (within 2 MiB of the limit) or “too large” (full-screen app: “INDEX TABLES (AMPR EMU NG)”). This is an estimate; NG's message at the start is the binding one. If it is too large, it helps to pack the game with fewer files.

Limits and notes

  • Unsigned executables: if the app packs into a new folder, it writes plain ELF files as FSELF (see the chapter “Games”); when packing in the game folder they stay as they are. With zstd the switch “Sign executables as FSELF” (on by default) replaces them in the game folder. The window shows beforehand how many there are.
  • APR-EMU rejects sets with more than 2,000,000 files, 16,000,000 blocks or 1,024 pack files. For big games the app uses larger blocks.
  • The index, .runtime and packs of a game belong together. Never swap single parts, and change nothing while the game is running.
  • According to its author, APR-EMU 0.4.2.1 still has a crash with saved data. Keep the original until you have played long enough.
  • Origin: format and rules follow drakmor/ampr_emu (docs/ASSET_PACK_WORKFLOW_EN.md, GPL-3.0); models were theghostonline/PS5-LZ4-Compression and danthespal/MkPFS.CSharp. From LZ4 Compression (Husam Osman, GPL-3.0) come the list of files that must stay loose, the permissions 0777, the repair during the check and the choice of tested profiles; rebuilt, not copied.
  • Ideas and knowledge: exFAT2AMPR by V-10 (GitHub, GPL-3.0 with additional terms, “Made by V-10”): the list that “Automatic” leaves loose, the recording for profile creation (after his port of ampr_pack_profile.py) and the upkeep of the game plugins.

Play time

When you played, for how long and how warm the console got: totals for today, 7 and 30 days, the last 14 days as bars, the most played games and the recent sessions with peak temperatures; can be saved as CSV.

Back up saved data

Copies the saved data as the console stores it – encrypted and unchanged – to a USB stick, a disk or the internal SSD (PS5-Sicherung/Spielstaende/<Datum>). Every file is verified; “Verify” reads a backup again later. The list is split per user into PS5 and PS4 games; the app does not touch apps such as YouTube.

  • Restore (per game): the app first backs up the current state, writes the new files next to the old ones first, verifies them and only then replaces the old ones. Backups from another console cannot be restored.
  • Delete removes the saved data of a title after a question that names it. The app first backs it up to the chosen drive; if there is none, a note says that it is deleted without a backup.
Backing up, restoring, deleting, reading out and importing only work when no game is running – not even a paused one. Otherwise close the game (“Close game” on its card).

Transfer to another console

  1. Read out: press As ZIP at the title. The console reads the saved data out in the clear with its own means, and the app packs the files into a ZIP file (one each if a game has several saved data). The saved data on the console stays unchanged. The file is ready for download under “Transfer to another console”.
  2. Import: on the other console, choose the ZIP file(s) under Import saved data – from this app or from Garlic SaveMgr. The app shows title, files and size without changing anything; then choose the user.
  3. The app backs up existing saved data of this title, has the console create a new image, writes the files into it, reads each one back and compares it. Only then does the image go to its place; if anything fails, everything goes back to the state before.
  4. Start the game and check the saved data.
The ZIP file is not encrypted. The account ID is removed from it, other owner details stay (the import needs them): only pass it on to people you trust with it.
  • Owner details: the app takes them from another saved data of the same user on this console. If there is none, it imports anyway, and the app says that the game may not accept the saved data.
  • Image format: saved data in the newer format is created as a classic image; whether the game accepts it only shows when the game is started (the app says so beforehand). Whatever it cannot create yet, it refuses with a reason.
  • PS4 saved data works the same way; the console makes a new key when importing.
  • If a title has more than 16 saved data, the app reads nothing out and says so. An interrupted import (power loss, crash) is finished or taken back by the next start of the app.
  • ZIP files that were read out are removed with “Delete” in the section; uploaded ones that nobody imported within a day are tidied away by the app itself.

Full-screen app: the way goes via a USB drive. In the menu of a game (Square button), “Read out as ZIP to …” writes the file to PS5-Sicherung/Spielstand-ZIP on the drive. On the other console, the “ZIP files” list shows this folder; the X button looks at a file, then “Import for <user>” (several: “Import all … saves”). File names only with letters, digits, “_”, “-” and “.”.

Packages

Finds .pkg files on USB drives and disks (in the main folder and in the folder pkg) and in console storage (/data/pkg) and shows the picture, name, title ID, version, type and size.

  • Install … – the console installs the package itself, the app shows the progress. If the console refuses, a plan below it shows what is in the way.
  • Add to queue – install packages one after the other. “All packages of this title” puts the game, updates and add-ons in the right order. A refused package is skipped with the reason; on an error the queue halts (“Continue”, “Retry”). It lasts as long as the app is running.
  • Split… – large packages into parts for FAT32 sticks (up to 4 GB per file) or discs; the original stays.
  • Install from the PC (browser only) – choose a .pkg on the computer or drag it onto the card; it is transferred during the installation, not stored. The page must stay open.
An aborted installation attempt can leave space reserved: free it on the console in the download list with “Delete”.

Disc in the drive

The Disc tab on the Games page shows which disc is in the drive and makes an image (ISO) of a PS2 DVD or PS3 disc. Without a drive (Digital Edition, a Pro without an attached drive) there is no such tab.

  • Switch on: only with the switch on does the app ask the drive; the choice stays saved.
  • Detection: kind of disc (PS2 DVD-ROM, PS3 BD-ROM, PS4/PS5 BD-ROM …) and title ID, such as SLES-52780. PS4 and PS5 discs are only recognised. The drive cannot read PS1 and PS2 CDs.
  • Create image writes the ISO to /data/PS5-Cooling-Center/disc/, with progress and time left, then with CRC-32, MD5 and SHA-1. “Cancel” deletes the unfinished file. While it runs, the console does not go into Rest Mode by itself.
  • Copy new discs automatically (off by default) makes the image as soon as a disc is inserted.
  • Redump: if /data/redump.db is on the console (built on a PC with tools/build_redump_db.py from ps-disc-detect, up to 64 MB), the image gets its name from the list and is compared with the checksums (“checked against Redump”).
  • You delete an image with “Delete” or in the file manager.

Dumping disc games

“Dump disc games” lists every game installed from disc. Choose a target (Settings → Location), insert the disc and press Start dumping: the app starts the game and dumps it by itself after the load time (default 30 s). The console reports “Dump started”, “Dump done” or “Dump failed”. The dump queue handles several games one after the other. If another game is already running, the game already has a dump or a queue is running, the button is just called “Start”, and “Dump” follows by hand. Only for backups of your own games.

The tab is based on ps-disc-detect (GPL-3.0), whose approach the app has rewritten.

File manager

View and change the folders of the console and the drives: upload, download, new folder, rename, copy, move, delete – also in system folders such as /user and in the app's folder.

  • View only: / itself, /mnt, /dev, /proc and links. The folders directly under / and /mnt (e.g. /user, /data, /mnt/usb0) cannot themselves be renamed, moved or deleted, but their contents can. Whatever the console has mounted read-only (e.g. /system) refuses changes by itself.
  • Drives are named as on the console: /mnt/usb0 is “usb0”.
Under /system_data and /user lie the console's databases and settings, in the app's folder its settings and logs. Deleting or moving the wrong thing there risks a console that no longer starts or has to be set up again.

Sorting, viewing, editing

  • Sort by name, size or date (the arrow reverses the direction); folders are at the top. The box above the list selects all entries.
  • Calculate size (⋯ menu of a folder) or Folder sizes for all folders in the view; a very large folder is reported with “at least” after about 8 seconds.
  • View shows pictures (PNG, JPG, GIF, WebP, BMP, ICO) and the beginning of text files (up to 256 KB).
  • Edit opens text files up to 64 KB in an editor; “Save” writes them back. Download larger files, edit them and upload them again.
  • Game titles: folders and images whose name starts with a title ID (e.g. PPSA01325, PPSA01325.exfat, CUSA05041-app) show the game's title – from their own param.json or param.sfo, or from the games the console knows.

Searching

The Search field instantly shows only the entries of the open folder whose name or game title contains the term; case does not matter. With * and ? the whole name must match: *.pkg finds all packages, PPSA????? all folders with a title ID.

Include subfolders searches all folders below – from the drive, the whole drive (console, USB, M.2, NTFS), but not the whole system (/), links or other drives below. At most 2,000 matches; Cancel ends the search. Matches work like normal entries; Open folder jumps to the match. Full-screen app: Triangle button → Search …, Include subfolders: on/off, End search; the X button opens a match, the Circle button ends the search.

Copying, moving, uploading, deleting

  1. Tick entries (or use the ⋯ menu of an entry) and press Copy to or Move to.
  2. At the top choose a drive or a place, go into the target folder and press Copy here or Move here.
  3. If the name already exists in the target: Replace (a file is first written next to it and swapped in at the end, a folder is merged), Keep both (“Name (2)”), Skip or Cancel.
  4. The display names files, source and target, percent, rate and time left. Cancel removes the entry that was started in the target again.

Alternatively via the clipboard: Copy or Cut, go to the target folder, Paste here – the full-screen app works this way too. Upload and Upload folder (browser only; on a PC also by dragging onto the list) ask the same way about existing names.

Delete always asks first: the window names the names, kind and size, for folders also the number of files. Only Delete in the window deletes for good; Cancel (it has the focus) leaves everything as it was.

Protected: links are never followed, a mounted drive cannot be deleted as a whole, and copying and deleting never cross over to another drive.

Eject a USB drive safely

Next to every USB drive among the locations there is Eject (full-screen app: Square button on the drive under “Locations”, or Triangle button → More → Eject safely). For this the browser switches to System → Storage; it is the same eject with the same conditions (chapter “System & log”). Only unplug the drive once the console reports “… is ejected and can be unplugged”.

NTFS drives (Windows)

The console cannot mount NTFS itself; the file manager reads and writes such drives with a driver of its own. While it is open, a plugged-in NTFS stick appears under the locations after a few seconds as ntfs0 (more: ntfs1 …); every NTFS partition is a location of its own.

  • Works: viewing, downloading, uploading, new folder, copying and moving in both directions, deleting (asks first, as always).
  • Does not work: renaming, editing and replacing; with the same name, “Keep both”, “Skip” and “Cancel” remain. Names that Windows does not allow are written by the app with _. Games on it can neither be started nor mounted – copy them to the internal SSD or an exFAT drive first.
  • Read-only: if this appears above the list, Windows has not fully let go of the drive (unplugged without “Safely remove”, Fast Startup, a pending chkdsk check), or it was unplugged from the PS5 in the middle of writing. The note says what to do on the Windows PC.
  • Eject works without ShadowMountPlus and at once; the app then reports “ntfs0 can be unplugged now.” If it is using the drive right then, it does not eject. An ejected drive only appears again after it is plugged in again.
On NTFS, the app's driver writes, not the console. Back up important data first, and never unplug the drive while the app is writing – use “Eject” first. After a write error the app lets go of the drive and asks you to check it with chkdsk on a Windows PC.

The NTFS driver comes from PS5-NTFS-BROWSER by abcde6543 (GPL-3.0-or-later).

Payloads

See and quit running payloads, start saved ones with one click – from /data/PS5-Cooling-Center/payloads or from the USB stick (root or folder payloads). They are started via the console's ELF loader (port 9021). .elf and .bin files (etaHEN) count as payloads.

  • Profiles: a named sequence of payloads and pauses that “Run” starts step by step. The app runs a startup profile after every start of its own (with protection against endless loops). “Import from PC” loads new payloads into the folder; “Back up profiles” and “Load profiles” exchange profiles as a file.
  • Download payloads: the same list as in the Payload Manager (itsPLK) plus the payloads of strongt1me, with search and categories. “Load list” fetches it once from GitHub; after that the page refreshes it at most every three hours. “Download” only saves once the SHA-256 checksum matches; with a newer version the card shows “old → new” and “Refresh”. “Delete” only removes what the app downloaded itself; a foreign file with the same name is replaced only after a question.

Profile

Change the display name of your account (up to 16 characters) and choose a profile picture – one of the 30 built-in ones or your own. Name and picture appear on the Home screen after switching users; “Restore previous” brings back the picture before.

  • Browser: choose your own picture from the phone or PC, “Crop” or “Fit”, then “Apply profile picture”.
  • Full-screen app: put your own pictures (JPG or PNG up to 16 MB) into /data/PS5-Cooling-Center/Profilbilder or on a USB stick (root or folder Profilbilder); they appear first, with the mark “OWN”. The X button applies a picture, the Square button brings back the previous one, the Triangle button changes the name.

Further down (full-screen app: “Account” view):

  • Activate offline account: sets the account ID, type “np” and flags (like OffAct) for an existing user; the name stays. Needs an active jailbreak.
  • Write fake sign-in sends np-fake-signin to the ELF loader; it writes auth.dat, config.dat and registry entries. Reset fake sign-in deletes only these and leaves the offline account untouched.
  • Back up and transfer profiles (browser only): export “Web profile” (the settings of this browser) and “Game profiles” (the target temperatures per game) as a file and import them on another device.

System & log

System shows the console, firmware, uptime, the storage of all drives, network, display, the cooling performance over the weeks and a QR code with the page's address (scan it with a phone on the same network). The Expert mode switch is here too.

  • ShadowMountPlus (at the very top; full-screen app: System → ShadowMountPlus): whether the version before or from 1.7beta12 is running (new config.ini; default “Detect automatically”), and its switch “Update fakelib automatically” (off for AMPR EMU NG).
  • Serial number: by default only the last four characters. Full shows the whole number, Shortened switches back (full-screen app: X button on the row). Shown in full, it can be read by every device on the home network.

Eject a USB drive

Under “Storage”, every USB drive (/mnt/usb0 to usb7, /mnt/ext0) has Eject (full-screen app: System → Memory, X button). The console detaches a drive by force and asks nobody whether anything on it is still open. That is why the app only ejects when

  • ShadowMountPlus 1.7beta10 or later is running (it carries out the eject),
  • no job of the app is running (copying, converting, moving, saved data, packages, disc image …),
  • PS4Mount is not playing any games from the drive and Kraken Mount has not mounted an image from it,
  • the app itself no longer has anything open on it (it checks other programs only where the console allows it).

Otherwise it says what is still running. Beforehand it waits until nothing of it reads from the drive any more, and writes everything to the drive. Only unplug once “… is ejected and can be unplugged” appears (after two to seven seconds). The console picks up some drives again by itself afterwards.

The Eject button on ShadowMountPlus's own page does not know about this app's jobs: while a job is running, eject only through this app. If the console or the app crashed during the last eject, ejecting stays blocked until you allow it with “Allow ejecting again” (Storage or file manager). Safer then: switch the console off and unplug the drive afterwards.

Log

Log lists every measurement, control action and message of the app (exportable). Live kernel log shows the console's log as it is written – with filter, pause, save, download and recording. The app log is also in /data/PS5-Cooling-Center/app.log (from 1 MB the old file becomes app.old.log) and so survives a crash: every start begins with ===== … gestartet =====, a regular end writes ===== … beendet: <reason> =====.

Security on the home network

  • The interface has no login: every device on the home network can read and change things.
  • Do not set up port forwarding to port 8086 – the console does not belong on the open internet.
  • To use it only on the device itself: in expert mode, under Cooling → Advanced settings, set the bind address to 127.0.0.1 (“Local only”).
  • The app refuses requests from foreign websites (error 403). Only the console's IP address, localhost and names with a home-network ending (.local, .lan, .home, .home.arpa, .internal, .localdomain, .intranet) are accepted; for a name such as ps5.fritz.box, use the IP address.
  • ShadowMountPlus (port 10101) accepts requests from the whole home network, also without a login. It can be restricted in its config.ini with api_bind_address=127.0.0.1; the app talks to it over 127.0.0.1 anyway.
  • Kraken Mount (port 8097, only when switched on) and Dump Forge (port 8095, only during a conversion) are programs by other authors that the app starts. They listen on the whole home network and check neither Host nor Origin; the app's bind address and protection do not apply to them. If you do not want that, leave Kraken Mount off.
