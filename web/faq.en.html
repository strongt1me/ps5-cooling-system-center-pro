FAQ

Quick answers about starting, the fan, games, packages, saved data, the file manager and security.

General
What does the app actually do?
It controls the PS5's fan according to a target temperature – calm and slow rather than loud and hectic – and offers a web interface for games, packages, saved data, files, payloads, profile and system information.
Do I need internet?
No. The app only connects to programs on the console and to the browsers on your home network. The only exception, in the browser: the “Credits” page checks once whether github.com is reachable, so that the links become clickable. The console needs internet only when you trigger it yourself: “Load list” under “Download payloads” fetches the payload lists from GitHub (itsPLK and strongt1me), then “Download” fetches the single file; plus “Check for a new AMPR EMU NG version and load it” (the “APR-EMU version” window of a game) and “Download newer version from GitHub” (Dump Forge in the convert window, and KrakenMount). Only after the first “Load list” does the page renew the payload list by itself when it is opened, at most every three hours.
Which firmware is supported?
Firmware 12.00 on a PS5 Pro (CFI-7021) is tested; users report that the app also runs on 4.xx to 10.xx and on 13.60. The app is built with an SDK whose start-up code knows firmware 1.00 to 14.22; on the other versions the app has not been tested.
What has to run on the console for the app to work?
A PS5 with a jailbreak and a loaded ELF loader (elfldr, port 9021). For fan control kstuff must also be loaded; without kstuff the display and the web interface run, and the control reports “not available”. ShadowMountPlus is optional, but is needed for the tiles on the home screen, mounting and unmounting games, moving, unpacking and ejecting USB drives (mounting, unmounting and ejecting from ShadowMountPlus 1.7beta10). A browser on the home network is enough to operate it.
Does the app cost anything?
No. It is free software under the GNU GPL, version 3 or later.
Starting & using
Do I have to send the app again after every restart?
Not if you use a tile: FAKE86921 and FAKE86922 start the app themselves. Without a tile, yes – the ELF runs in memory and has to be sent to port 9021 once after every restart. The settings are kept.
The tile only opens an empty page – why?
This concerns the former media tile (PSCC69690): it did not start the app. Use the tile FAKE86922 (browser) or FAKE86921 (fullscreen); both start the app themselves.
Which tile do I need: FAKE86921 or FAKE86922?
FAKE86921 is the fullscreen app: it shows the app on the TV and is operated with the controller, with no browser at all. FAKE86922 starts the app just the same and opens the web interface in the console's browser. Both bring the app with them and start it themselves if it is not running yet; you can have both side by side. The folders from the zip files belong in /data/homebrew/, and ShadowMountPlus creates the tiles.
I copied new tile folders, but the app still shows the old version – why?
Up to 1.77.0 the tiles only sent their app when none was running, so an older app that was still running simply stayed. Since 1.77.1 a tile replaces an older running app when you tap it. An equal or newer one stays, and if a job is running (packing, copying, installing …) the tile leaves the app alone – open it again after the job. If the tiles on your console are still from 1.77.0 or older, send the new ELF once to port 9021 (it ends the old instance itself) or restart the console.
When I open the tile after a game, “Device busy” appears – what to do?
Usually just tap the tile again. So that it does not happen in the first place, the app pauses a game in the background itself as soon as the home screen is in front (switch Pause the game in the background below the operating mode on the Cooling page, on by default; in the fullscreen app under Settings). If the console refuses the start anyway, the app reports “Please be patient for a moment” and starts the tile once more itself. If the message stays with a game that you only mounted but never started, the Unmount button on the Games page helps.
How do I open the interface on a phone or PC?
Open http://<PS5-IP>:8086/ in the browser. The IP is in the notification on the TV after the start.
Can I start the app twice?
Usually it sorts itself out: if you send the ELF a second time or a tile starts a newer app, the new instance ends the older one itself. If that fails (a very old build; the console reports “Port 8086 is held by an older instance of this app”), you end the old one on the “Payloads” page (Already loaded payloads → “Quit”) or restart the console. Two instances at the same time both control the fan and interfere with each other.
How do I see the temperature without opening the page?
Press the controller's mute button twice quickly: the temperature and fan speed appear at the top left (without a sound).
Why doesn't the page move when a window is open?
That is on purpose: while a window is open, the background stays still, and the right stick only scrolls the window itself.
In which languages is the interface available?
German, English, Italian, Spanish, French, Russian and Swedish. You choose the language at the top right of the header (in the fullscreen app: Options button → “Sprache / Language”); the manual and the FAQ are available in all seven. Notifications that the console shows on the TV stay in German.
A text is still in German – is that a bug?
Not a bug in the app, but a gap: rare texts and console messages are not translated into every language and then appear in German. Please report them; the dictionaries are easy to extend.
How do I open the sidebar in the fullscreen app?
With the touchpad button. Left on the d-pad belongs to the page (e.g. the grid of profile pictures); L1 and R1 switch directly to the previous or next area.
How do I operate the fullscreen app with the controller?
Touchpad button: sidebar. L1/R1: previous and next area, L2/R2: the sub-tabs. D-pad: select and change values. X button: start or confirm, Circle button: back. Square button: actions for the selection, Triangle button: details or “More”. Options button: menu with “Open web interface in the browser”, “Reload”, “Sprache / Language”, “Quit app” and the power options. The bar at the bottom always shows what the buttons do right now. “Quit app” closes only the fullscreen app; the app on the console, and with it the fan control, keeps running.
Where do I put my own profile pictures for the fullscreen app?
In /data/PS5-Cooling-Center/Profilbilder or on a USB stick (root or folder Profilbilder), as JPG or PNG up to 16 MB. After a few seconds they appear first on the Profile page, marked “EIGENES”.
Why is my USB stick called “usb0”?
That is what the console itself calls it (/mnt/usb0). So the app counts from 0 as well: usb0, usb1 …
Why does the app show only part of my serial number?
By default the app shows only the last four characters (••••8023): it has no login, and the whole number could otherwise be read by every device on the home network. To see it in full, press Full in the “Serial number” row on the System page (fullscreen app: the X button on the row); Shortened switches back. The choice is saved on the console and applies to the browser and the fullscreen app.
Fan & temperature
Which target temperature makes sense?
66 °C by default. Cool = 62 °C, Balanced = 77 °C, Quiet = 91 °C. Higher means quieter and warmer; up to 72 °C is a good range for most people. 91 °C is the value the console sets itself: as quiet as without the app, but the console gets noticeably warmer; the warning threshold moves with it automatically (target + 2 °C).
How do I make the fan even quieter?
On the Cooling page there are three places: raise the Target (the “Quiet” quick select sets 91 °C), choose the Operating mode “Quiet” (recommended; it does not change the target, only how strongly the fan responds to heat) and lower the Fan speed ceiling (30 to 100 %, 100 % by default). The ceiling does not apply above the emergency limit or in the fan guard. If you only want it quieter at night, switch on Night mode: between two times, a night target that is usually warmer applies. Quieter always means warmer too.
Can the app overheat my console?
The app only holds the temperature you set. Above the safety limit, all consideration for noise is dropped and the fan goes quickly to full speed; the PS5's firmware always protects itself independently of that. On top of that the fan guard watches: if the regulation hangs or it still gets too hot, it sets full cooling or hands the fan back to the console.
The console shows “Temperaturwarnung” – what does that mean?
The app warns when the processor reaches the “Warning from” threshold (80 °C by default, 5 °C more for the main chip): with a notification on the screen, and above the safety limit with a window. With a high target this would happen all the time, so in automatic mode the threshold rises with the target (switch “Warning threshold follows the target” in the advanced settings, on by default, never lower than target + 2 °C). If the warning comes anyway, make sure there is free ventilation (dust, distance from the wall) or lower the target; “Warning from” can also be raised.
Why doesn't the fan spin up immediately?
The control is deliberately slow: it works with an average, lets the speed rise gently from about 10 °C below the target and adjusts in small steps.
What happens when I quit the app?
Then the console controls the fan itself again according to its normal settings. The same applies when “Automatic mode” is switched off.
The fan is “not available” – what can I do?
kstuff is not loaded. Without kstuff, the app cannot reach the fan controller. Load kstuff and send the app again.
Games, packages & saved data
Does deleting a game delete my saved data?
No. Saved data is always kept when a game is deleted. Nothing is deleted until you confirm “Delete” in the window; the app never deletes a running game.
Which format should I choose when converting?
ffpfsc is compressed and recommended. ffpkg and exFAT are uncompressed. FPKG (a debug .pkg that Dump Forge writes) you only need for Kraken Mount (tab “KrakenMount”). Please recreate older .ffpkg files made with versions before 1.48.0. For exFAT and ffpkg the game can additionally be packed into LZ4 or zstd packs on the way (chapter “Games”).
Is the original deleted when I convert, copy or unpack a game?
No, by default it stays (“Original afterwards”: Keep). In the window you can choose Delete instead (the app asks first and names the name, size and path; saved data stays) or Move (first a checked copy into a folder of your choice, then the original is deleted). The original is deleted or moved only after the job has ended well; if it fails or you cancel it, the original stays untouched. Purpose: the same title should not lie on the console twice, otherwise ShadowMountPlus reports it from two places (chapter “Games”).
The window says “Unsigned executables” – what does that mean?
The game's executables (eboot.bin, .prx, .sprx) are plain ELF files, and the console does not start such files. When converting, and when packing into a new folder, the app writes them as FSELF (fake-signed); the game folder stays as it is. Packing in the game folder itself leaves them unchanged; with LZ4 you can choose the copy as a new folder next to it, zstd always packs in the game folder and replaces them there with FSELF versions as long as you leave the switch “Sign executables as FSELF” on.
A large package does not fit on my FAT32 stick.
FAT32 allows at most 4 GB per file. Under “Packages”, “Split…” cuts a package into suitable parts – the original stays unchanged.
An installation was aborted – where is my storage space?
The console reserves the space immediately. Remove the aborted entry from the console's download list with “Delete”.
Where are my saved data backups?
On the drive you choose when backing up, in the folder PS5-Sicherung/Spielstaende/<Datum> – on the internal SSD under /data.
Can I restore saved data from another console?
Not a backup made by the app: it is tied to its console and can only be verified there. To switch consoles, the “Saved data” page has the section “Transfer to another console”: press “As ZIP” at the title (PS5 and PS4), choose the ZIP file on the other console under “Import saved data” and pick the user (chapter “Back up saved data”). The ZIP file is not encrypted.
My game does not start after LZ4 packing. What now?
Tap “Unpack LZ4 …”: all files come back, checked byte for byte. Then test the game unpacked first with the same APR-EMU version. If it does not run like that either, it does not tolerate this APR-EMU. In detail in the chapter “LZ4 asset packs: step by step”.
LZ4 or zstd: which should I choose?
LZ4 is read by drakmor's APR-EMU (0.4.2.1 test-pack) and by AMPR EMU NG too; the app packs only the game data and leaves programs, media and delicate files loose (profiles, “Automatic”). zstd is read only by AMPR EMU NG, packs the whole game except the system files and usually saves more space. If a game runs with LZ4, there is no reason to switch. Both can be unpacked again with one click; to switch, unpack first.
Can I pack a game into LZ4 or zstd packs while converting it?
Yes, for exFAT and ffpkg of a PS5 game folder: choose the group “Packing (AMPR packs)” in the convert window. Dump Forge writes the image and packs on the fly; the original stays unchanged, and the source is read twice, so it takes longer. zstd works only with AMPR EMU NG, which Dump Forge puts into the game itself. The choice is greyed out for PS4 games and for games that already lie in packs. Details in the chapter “Games”.
Can the app copy discs?
A PS2 DVD or PS3 disc, yes: the Disc tab on the Games page, “Create image” makes an ISO with CRC-32, MD5 and SHA-1. PS4 and PS5 discs are only recognised. The PS5's drive cannot read PS1 and PS2 CDs.
Can I back up (dump) a game that is installed from disc as a folder?
Yes, in the Disc tab under “Dump disc games”: it lists the PS5 and PS4 games that are installed from disc. Choose a target under “Settings” → “Location”, insert the disc and press Start dumping on the game: the app starts the game and dumps it by itself after the load time (the game keeps running meanwhile). Several games one after another are handled by the “Dump queue”. Only for backups of your own games (chapter “Disc in the drive”).
I only use the ELF – do I need Dump Forge separately for the “FPKG” format?
Not necessary at all: since 21 November 2026 Dump Forge 0.6.0 is inside the app's ELF (packed; the ELF is about 8 MiB bigger because of it) and is unpacked in memory for every job; nothing is written to the console. This also applies to packing while converting to exFAT or ffpkg. A newer version you fetch in the convert window with “Download newer version from GitHub” (only on a button press) or put there yourself: copy the file ps5-dump-forge-VERSION-ps5.elf (the version only digits and dots, newer than 0.6.0) to /data/PS5-Cooling-Center/dumpforge/, for example by FTP; the highest version wins. The app makes the folder at every start.
My PS4 games from USB or my FPKG games do not show up – why?
“PS4 PKG from USB” (PS4Mount) and “KrakenMount” (Kraken Mount) have been switched off by default since 21 November 2026. Open the tab on the Games page and turn on the switch Switch on at the top; the app remembers the choice (on as well as off) and then starts both by itself every time it starts. After an update, if you had never switched it on, you have to switch it on once. The games then appear with their icon on the home screen.
File manager
Why can't I change some folders?
Since 1.75.3 everywhere, including system folders such as /user or /user/download and the app's own folder. Only / itself, /dev, /proc, mounted drives as a whole, the folders directly under / and /mnt themselves (for example /data, /user, /mnt/usb0; their contents stay changeable), folders under which something is mounted, and links are locked; what the console has mounted read-only it refuses by itself. Take care under /system_data and /user: they hold the console's databases and settings.
May I change anything in the app's folder?
Yes, since 1.75.3 the app's folder (/data/PS5-Cooling-Center) can be changed too. Caution: the app's settings and logs are stored there; change only what you know.
Is anything overwritten when copying?
Only if you want it. If a name already exists in the destination, a window asks: “Replace”, “Keep both” (the new entry is called “Name (2)”), “Skip” or “Cancel”. Replace writes a file next to the old one first and swaps it in at the end; a folder is merged. Copying games on the Games page, by contrast, never overwrites.
What happens with “Cancel”?
The operation stops; whatever of the started entry had already been written to the destination is removed again.
How do I view a file without downloading it?
With “View” on the file: pictures (PNG, JPG, GIF, WebP, BMP, ICO) appear in a window; for text files, the beginning up to 256 KB. Binary files can only be downloaded.
Can I edit a text file directly on the console?
Yes: for text files up to 64 KB (for example .txt, .ini, .json, .toml), Edit in the ⋯ menu of the file opens an editor; “Save” writes the file back. This only works where the file is writable; otherwise the window only shows the text. Download larger files, edit them and upload them again.
Can I sort the list by size or date?
Yes: above the list you choose “Name”, “Size” or “Date”; the arrow reverses the order. With “Folder sizes”, the console also counts the size of the folders.
How do I eject a USB stick safely – and why is it back afterwards?
In the file manager, next to every USB drive in the row of locations there is an Eject button (in the fullscreen app: the Square button on the drive under “Locations”); the same eject exists under System → Storage. It runs through ShadowMountPlus (from 1.7beta10) and works only when no job of the app is running, PS4Mount plays no games from the drive and the app itself no longer has anything open on it (it checks other programs where the console allows it). The console detaches a drive by force and asks nobody; that is why the app first waits until nothing of it reads from the drive any more. Unplug the stick only when the console says “… is ejected and can be unplugged”. While “Ejecting …” is still shown (two to seven seconds, depending on the drive), do not unplug it yet. The console only detaches it by software: it picks up some drives again by itself after a few seconds, others only after they are plugged in again. If the console crashed during the last eject, ejecting stays blocked until you allow it again; safer then: switch the console off completely, then unplug.
Can the app read and write Windows NTFS drives?
Yes, in the file manager – even though the console itself does not mount NTFS. The drive appears under the locations as ntfs0. Uploading, new folders, copying, moving and deleting work; renaming, editing and replacing do not, and games cannot be started from it. If it says “Read-only”, Windows has not fully let go of the drive; the note says what to do on the PC. A stick that was unplugged in the middle of writing is read-only as well until a Windows PC has checked it. Press “Eject” before unplugging it.
Can I search for files?
Yes (since 25.11.2026): the “Search” field above the list instantly filters the open folder (part of the name; with * and ? the whole name). With “Include subfolders” the console also searches every folder below, from the drive the whole drive; “Open folder” jumps to the match. In the full-screen app via △ → “Search …”.
Problems & security
“The drive has disconnected (Device not configured)”
Almost always the USB cable, the port or too little power. Try a different, short cable directly on the console; if there are problems afterwards, restart the console.
I get error 403.
The app refuses requests that come from outside websites, and since 21 November 2026 also addresses with a name that does not have a home-network ending such as .local, .lan or .home (for example ps5.fritz.box). Open the interface directly via the console's IP address.
Is the interface password-protected?
No. Every device on the home network can use it. So do not set up port forwarding; if you like, set the “Bind address” under Cooling → “Advanced settings” to 127.0.0.1 (“Local only”). ShadowMountPlus (port 10101) and, as long as they are running, Kraken Mount (port 8097, off by default) and Dump Forge (port 8095, only during a conversion) also accept requests from the whole home network without a login; the app's bind address does not apply to them. You restrict ShadowMountPlus in its config.ini with api_bind_address=127.0.0.1; leave Kraken Mount switched off.
Unknown folders with zip files in /data/homebrew?
They usually come from another tool with automatic saved data backup (e.g. ProsperoMgr), not from this app.
Backing up, restoring or “As ZIP” does not work because a game is running – what to do?
Saved data is only touched when no game is running – not even a paused one: a game waiting in the background can still hold the saved data open. Close the game (Close game on its card) and try again. This applies to backing up, restoring, “Delete” of saved data, “As ZIP” and “Import saved data”.
Is this legal?
The app contains no games, no firmware, no foreign keys (only a publicly known one for self-built test packages) and nothing that circumvents copy protection. Modifying a console may violate terms of use; whoever does it bears the risk. Piracy is not supported.
The page stutters when scrolling in the PS5 browser.
Since 1.71.2 the background of the “Standard” design is a single colour, and the regular refreshes pause briefly while you scroll. If that is not enough, choose the “Optimal” design (the fastest to draw).
After a game the console shows an error message (“Device busy”) when I tap the tile – what to do?
Since 1.86.5 the app pauses a game in the background itself as soon as the home screen is in front (Cooling → “Pause the game in the background”, on by default). The tile then starts without a failed first start and without a message. If the switch is off, or you tap within the first second after the PS button, the app starts the tile once more by itself after a few seconds.
After using “Mount” on a game, no other game and no tile starts any more (“Device busy”) – why?
ShadowMountPlus has only one place for a mounted game that has not been started yet; as long as it is taken, it refuses every other start, and the console shows a launch error. Start the mounted game or press Unmount on it (the Games page shows a yellow notice for this; in the fullscreen app the row carries the mark MOUNTED). The app also releases a game it mounted itself and nobody started, on its own: at once when it starts another game itself or the console refuses another start (then simply try the start again), otherwise after 30 seconds.
